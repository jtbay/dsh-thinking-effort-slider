# 思考强度滑条 (Thinking Effort Slider)

在输入框卡片内部、模型选择控件正上方添加一条无边框的彩色思考强度轨道，左边缘与模型名称首字母 `D` 对齐，位于输入文字与模型按钮之间。圆点下方不再常驻文字。

## 功能

- **渐变色轨道**：轨道从 `off` 到 `max` 依次显示绿、蓝、金、红；四个圆点分别使用对应颜色，圆点颜色与渐变停靠点精确一致。
- **发送按钮联动**：当前选中等级的颜色会同步到输入框右下角的发送/停止按钮；`off` 绿、`low` 蓝、`high` 金、`max` 红，切换或拖动时实时更新。
- **输入框边框联动**：输入框卡片在空闲时使用当前等级颜色作为边框。
- **回复时仅保留泛光**：当前会话的助手正在回复（`session.running`）时，取消彩色边框和输入框自带的灰色描边/普通阴影，只在输入框周围保留同色柔光，并以 1.5 秒为周期脉冲闪烁；回复结束后恢复彩色边框并取消泛光。
- **点击显示等级**：点击圆点时，在**当前可见对话区域的正中央**显示一个圆角矩形提示，例如 `Max`，并用约 1 秒完成淡入、停留和淡出。拖动过程中不会弹出提示；点击已选中的圆点也会显示。
- **适配侧栏与窗口缩放**：提示显示时实时读取当前对话内容区域的边界，因此左侧栏展开、右侧面板打开或对话列被压缩时，提示仍会落在缩小后的对话窗口正中央。
- **鼠标拖动 / 点击**：按住轨道拖动时高亮圆点随指针移动，松开后应用；直接点击某个圆点也会应用该档位。
- **键盘可访问**：聚焦滑条后可用 `←` / `→`、`↑` / `↓`、`Home`、`End` 切换档位；无障碍值仍会读出当前等级。
- **跟随模型自适应**：档位、默认值和颜色都按当前模型在模型目录中公布的 `reasoning` 元数据生成。切换到 `DeepSeek-V4.1-Flash`、`DeepSeek-V4-Pro` 或其他模型后，轨道自动刷新；没有推理等级或只有一个等级的模型不会显示。
- **与模型选择器同步**：使用模型选择器同一个 `modelDirectories` 会话目录和 `selectModel` 通道，模型菜单与轨道双向同步。
- **新会话常驻**：注册在 hero 和普通对话都会渲染的 `conversation.input.right`，空白新会话无需先发送消息即可看到并操作。
- **无边框**：轨道本身不使用卡片、边框或背景，只显示彩色连线、圆点和悬浮提示。
- **错误提示**：提交失败时在轨道上方显示简短的错误信息，并保留原选择。

## 实现

- 注册到 `conversation.input.right`，用一个零宽锚点定位在模型选择控件之前。
- 轨道绝对定位在输入框卡片内部，按模型按钮的间距和内边距偏移，与 `DeepSeek…` 的 `D` 对齐。
- 颜色使用主题 alias token：绿色 `--dsw-alias-state-success-primary`、蓝色 `--dsw-alias-button-info-fill`、金色 `--dsw-alias-state-warn-primary`、红色 `--dsw-alias-state-error-primary`；圆点、渐变、提示点与发送按钮共用同一组 token。
- 发送按钮联动通过 `[data-composer-card]:has([data-thinking-color=…])` 定位输入区的 primary 操作按钮，不修改其他插件。
- 输入框边框使用 inset box-shadow 绘制，避免改变输入框尺寸；边框与发送按钮共用等级颜色 token。
- 泛光绑定 `useSession((session) => session.running)`；仅回复进行时渲染输入框的 `::before` 光晕，`tes-card-glow` 动画周期为 1.5 秒。运行态的样式规则会把卡片的彩色 inset 边框和普通 elevation 阴影一起重置为 `none`，因此回复期间只显示泛光、不出现灰色描边；回复结束即移除光晕并恢复彩色边框。
- 中央提示注册到 `shell.overlay`；点击时通过当前输入框所属的 `[data-conversation-content]` 实时计算对话区域中心，因此会跟随侧栏、右侧面板和窗口宽度变化。
- 提示使用 1000ms 的 CSS 淡入/淡出动画，内容在约 1 秒后移除。
- 不读取、不修改其他插件的 DOM；只使用 Slot、Locale、`modelDirectories` 和主题 token。
- 宿主半边为空，浏览器半边由 `dsh.client` 声明加载。

## 文件

| 文件 | 作用 |
| --- | --- |
| `client.js` | 滑条组件、拖动/键盘交互、颜色映射、中央提示、模型目录订阅、样式与文案 |
| `index.js` | 宿主插件入口（空实现） |

## 说明

滑条只显示当前模型明确公布的推理等级。模型目录尚未加载完成时滑条暂时隐藏，加载完成后自动出现。等级变更在下一个请求生效，正在生成中的步骤不会改变。
